# 机器学习统计学

> 统计学能让你知道，你的模型是真的有效，还是只是运气好。

**类型：** 构建
**语言：** Python
**前置要求：** 阶段1，第06课（概率与分布），第07课（贝叶斯定理）
**时间：** 约120分钟

## 学习目标

- 从头实现描述性统计量、Pearson/Spearman 相关系数和协方差矩阵
- 进行假设检验（t检验、卡方检验），并正确解释 p 值和置信区间
- 使用自助重采样法为任意指标构建置信区间，无需分布假设
- 通过效应量区分统计显著性与实际显著性

## 问题描述

你训练了两个模型。模型 A 在测试集上得分为 0.87。模型 B 得分为 0.89。你部署了模型 B。三周后，生产指标比以前更差了。发生了什么？

模型 B 实际上并没有优于模型 A。0.02 的差异只是噪声。你的测试集太小，或者方差太大，或者两者兼有。你把随机波动当作改进，推向了生产。

这种情况不断发生。Kaggle 排行榜的剧烈变动。无法复现的论文。基于几百个样本就宣布胜者的 A/B 测试。根本原因总是一样的：有人跳过了统计学。

统计学为你提供了区分信号与噪声的工具。它告诉你什么时候差异是真实的，你应该有多大信心，以及在你信任某个结果之前需要多少数据。每一个机器学习流水线、每一次模型比较、每一个实验都需要统计学。没有它，你就是在猜测。

## 核心概念

### 描述性统计：概括你的数据

在对任何东西建模之前，你需要知道你的数据长什么样。描述性统计将数据集压缩为几个数字，这些数字捕捉了数据的形态。

**集中趋势度量**回答“中间在哪里？”

```
均值：   所有值的总和 / 数量
         mu = (1/n) * sum(x_i)

中位数：排序后的中间值
         对离群值鲁棒。如果你有 [1, 2, 3, 4, 1000]，均值是 202，
         但中位数是 3。

众数：   出现最频繁的值
         对分类数据有用。对于连续数据，信息量通常不大。
```

均值是平衡点。中位数是分界点。当它们偏离时，你的分布是有偏斜的。收入分布通常是均值 >> 中位数（来自亿万富翁的右偏）。训练过程中的损失分布通常是均值 << 中位数（来自简单样本的左偏）。

**离散程度度量**回答“数据有多分散？”

```
方差：   与均值的平均平方偏差
         sigma^2 = (1/n) * sum((x_i - mu)^2)

标准差： 方差的平方根
         sigma = sqrt(sigma^2)
         与数据具有相同的单位，因此更易于解释。

极差：   最大值 - 最小值
         对离群值敏感。几乎从来不会单独使用。

四分位距（IQR）： Q3 - Q1
          中间 50% 数据的范围。
          对离群值鲁棒。用于箱线图和离群值检测。
```

**百分位数**将排序后的数据分成 100 等份。第 25 百分位数（Q1）意味着 25% 的值落在这个点以下。第 50 百分位数是中位数。第 75 百分位数是 Q3。

```
对于延迟监控：
  P50 = 中位数延迟      （典型用户体验）
  P95 = 第 95 百分位数   （糟糕但不是最坏情况）
  P99 = 第 99 百分位数   （尾部延迟，通常是中位数的 10 倍）
```

在机器学习中，你需要关心推理延迟的百分位数、预测置信度的分布，以及理解误差分布。一个平均误差低但 P99 误差糟糕的模型，对于安全关键型应用可能是无用的。

**样本统计量与总体统计量。** 当从样本计算方差时，除以 (n-1) 而不是 n。这是贝塞尔校正。它补偿了样本均值不是真实总体均值的事实。当分母用 n 时，你会系统地低估真实方差。用 (n-1) 时，估计量是无偏的。

```
总体方差： sigma^2 = (1/N) * sum((x_i - mu)^2)
样本方差： s^2     = (1/(n-1)) * sum((x_i - x_bar)^2)
```

在实际中：如果 n 很大（数千个样本），差异可以忽略。如果 n 很小（几十个样本），就有影响。

### 相关性：变量如何一起变动

相关性衡量两个变量之间线性关系的强度和方向。

**皮尔逊相关系数**衡量线性关联：

```
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)

r = +1： 完美的正线性关系
r = -1： 完美的负线性关系
r =  0： 没有线性关系（但可能存在非线性关系！）

范围：[-1, 1]
```

皮尔逊假设关系是线性的，并且两个变量都大致服从正态分布。它对离群值敏感。一个极端点就可能将 r 从 0.1 拉到 0.9。

**斯皮尔曼等级相关系数**衡量单调关联：

```
1. 将每个值替换为其秩（1, 2, 3, ...）
2. 对秩计算皮尔逊相关系数

斯皮尔曼能捕捉任何单调关系，不仅仅是线性的。
如果 y = x^3，皮尔逊给出 r < 1，但斯皮尔曼给出 rho = 1。
```

**何时使用哪种：**

```
皮尔逊：   两个变量都是连续的，且大致服从正态分布。
           你特别关心线性关系。
           没有极端离群值。

斯皮尔曼： 有序数据（排名、评分）。
           数据不服从正态分布。
           你怀疑是单调但非线性的关系。
           存在离群值。
```

**黄金法则：** 相关不意味着因果。冰淇淋销量和溺水死亡人数是相关的，因为两者都在夏季增加。你的模型准确率和参数数量是相关的，但增加参数并不自动提高准确率（参见：过拟合）。

### 协方差矩阵

两个变量之间的协方差衡量它们如何一起变化：

```
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))

Cov(X, Y) > 0： X 和 Y 倾向于一起增加
Cov(X, Y) < 0： 当 X 增加时，Y 倾向于减少
Cov(X, Y) = 0： 没有线性共移
```

对于 d 个特征，协方差矩阵 C 是一个 d x d 矩阵，其中 C[i][j] = Cov(特征_i, 特征_j)。对角线元素 C[i][i] 是每个特征的方差。

```
C = | Var(x1)      Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)      Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)     |

性质：
  - 对称：C[i][j] = C[j][i]
  - 半正定：所有特征值 >= 0
  - 对角线 = 方差
  - 非对角线 = 协方差
```

**与 PCA 的联系。** PCA 对协方差矩阵进行特征分解。特征向量是主成分（方差最大的方向）。特征值告诉你每个主成分捕获了多少方差。这正是第 10 课所涵盖的内容，但现在你明白了为什么协方差矩阵是正确的分解对象：它编码了数据中所有成对的线性关系。

**与相关性的联系。** 相关矩阵是标准化变量（每个变量除以其标准差）的协方差矩阵。相关性将协方差归一化，使所有值落在 [-1, 1] 范围内。

### 假设检验

假设检验是一个在不确定性下做出决策的框架。你从一个主张开始，收集数据，然后判断数据是否与该主张一致。

**设定：**

```
零假设（H0）：       默认假设，通常是“无效果”
备择假设（H1）：     你试图证明的东西

示例：
  H0：模型 A 和模型 B 具有相同的准确率
  H1：模型 B 的准确率高于模型 A
```

**p 值**是在假设 H0 为真的前提下，观察到与你的数据一样极端的结果的概率。它**不是** H0 为真的概率。这是统计学中最常见的一个误解。

```
p 值 = P(观察到如此极端的数据 | H0 为真)

如果 p 值 < alpha（通常为 0.05）：
    拒绝 H0。结果是“统计上显著的”。
如果 p 值 >= alpha：
    无法拒绝 H0。你没有足够的证据。
    这并不意味着 H0 为真。
```

**置信区间**给出了一个参数的可能值的范围：

```
均值的 95% 置信区间：
    x_bar +/- z * (s / sqrt(n))

其中 z = 1.96（对应 95% 置信度）

解释：如果你多次重复这个实验，95% 的计算出的区间会包含真实的均值。这并不意味着真实均值有 95% 的概率落在这个特定的区间内。
```

置信区间的宽度告诉你精度。宽区间意味着高不确定性。窄区间意味着你的估计是精确的（但如果你的数据有偏，不一定准确）。

### t 检验

t 检验用于比较均值。有几种变体。

**单样本 t 检验：** 总体均值是否与假设值不同？

```
t = (x_bar - mu_0) / (s / sqrt(n))

自由度 = n - 1
```

**双样本 t 检验（独立样本）：** 两个组的均值是否不同？

```
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)

这是 Welch 的 t 检验，它不假设方差相等。
除非你有特殊理由认为方差相等，否则总是使用 Welch 检验。
```

**配对 t 检验：** 当测量值成对出现时（同一模型在相同的数据划分上评估）：

```
计算每对的差值 d_i = x_i - y_i
然后对 d_i 值运行针对 mu_0 = 0 的单样本 t 检验
```

在机器学习中，配对 t 检验很常见：你在相同的 10 个交叉验证折上运行两个模型，并成对比较它们的得分。

### 卡方检验

卡方检验检查观察到的频数是否与期望频数相符。对分类数据有用。

```
chi^2 = sum((observed - expected)^2 / expected)

示例：语言模型的输出分布在各类别上是否与训练分布匹配？

类别       观察频数   期望频数
正面          120        100
负面           80        100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4 + 4 = 8

自由度 = 1，chi^2 = 8 给出 p < 0.005。
差异是显著的。
```

### 机器学习模型的 A/B 测试

机器学习中的 A/B 测试与网页 A/B 测试不同。模型比较有其特定的挑战：

```
1. 相同的测试集：   两个模型必须在完全相同的数据上进行评估。
                    不同的测试集会使得比较毫无意义。

2. 多个指标：       仅靠准确率是不够的。你需要精确率、召回率、F1、
                    延迟和公平性指标。

3. 方差：           使用交叉验证或自助法来估计每个指标的方差，
                    而不仅仅是点估计。

4. 数据泄露：       如果测试集在模型选择过程中被使用过，
                    你的比较就有偏差。需要留出一个最终的测试集。
```

**流程：**

```
1. 定义你的指标和显著性水平（alpha = 0.05）
2. 在相同的 k 折交叉验证划分上运行两个模型
3. 收集成对得分：[(a1, b1), (a2, b2), ..., (ak, bk)]
4. 计算差值：d_i = b_i - a_i
5. 对差值运行配对 t 检验
6. 检查：均值差是否显著不同于 0？
7. 计算均值差的置信区间
8. 计算效应量（Cohen's d）以判断实际显著性
```

### 统计显著性与实际显著性

一个结果可能在统计上显著，但在实际中毫无意义。当数据量足够大时，即使微不足道的差异也会变得统计上显著。

```
示例：
  模型 A 准确率：0.9234
  模型 B 准确率：0.9237
  n = 1,000,000 个测试样本
  p 值 = 0.001

统计上显著？是。
实际显著？0.03% 的提升不值得部署一个新模型的工程成本。
```

**效应量**量化了差异的大小，与样本量无关：

```
Cohen's d = (mean_1 - mean_2) / 合并标准差

d = 0.2：  小效应
d = 0.5：  中等效应
d = 0.8：  大效应
```

始终同时报告 p 值和效应量。p 值告诉你差异是否真实。效应量告诉你差异是否重要。

### 多重比较问题

当你检验多个假设时，其中一些会偶然变得“显著”。如果你在 alpha = 0.05 下检验 20 个东西，即使没有任何真实效应，也预期会出现 1 个假阳性。

```
P(至少一个假阳性) = 1 - (1 - alpha)^m

m = 20 个检验，alpha = 0.05：
P(假阳性) = 1 - 0.95^20 = 0.64

你至少有 64% 的概率得到一个假阳性。
```

**Bonferroni 校正：** 将 alpha 除以检验次数。

```
调整后的 alpha = alpha / m = 0.05 / 20 = 0.0025

仅当 p 值 < 0.0025 时才拒绝 H0。
保守但简单。当检验独立时有效。
```

在机器学习中，这在你跨多个指标比较模型、测试许多超参数配置或在多个数据集上评估时很重要。

### 自助法

自助法通过**有放回地重采样**你的数据来估计统计量的抽样分布。不需要对潜在分布做任何假设。

**算法：**

```
1. 你有 n 个数据点
2. 有放回地抽取 n 个样本（有些点会出现多次，有些点根本不会出现）
3. 在这个自助样本上计算你的统计量
4. 重复 B 次（通常 B = 1000 到 10000）
5. 自助统计量的分布近似于抽样分布
```

**自助法置信区间（百分位数法）：**

```
将 B 个自助统计量排序
95% 置信区间 = [第 2.5 百分位数，第 97.5 百分位数]
```

**为什么自助法对机器学习很重要：**

```
- 测试集准确率是一个点估计。自助法可以给出置信区间。
- 你不能假设指标分布是正态的（特别是对于 AUC、F1、top-k 精确率）。
- 自助法适用于**任何**统计量：中位数、两个均值的比率、两个模型之间 AUC 的差异。
- 不需要封闭形式的公式。
```

**用于模型比较的自助法：**

```
1. 你有模型 A 和模型 B 在相同测试集上的预测结果
2. 对每次自助迭代：
   a. 有放回地重采样测试索引
   b. 在重采样集上计算 metric_A 和 metric_B
   c. 存储 diff = metric_B - metric_A
3. 差异的 95% 置信区间：
   [差值的第 2.5 百分位数，差值的第 97.5 百分位数]
4. 如果置信区间不包含 0，则差异是显著的
```

这比配对 t 检验更稳健，因为它不依赖于任何分布假设。

### 参数检验与非参数检验

**参数检验**假定数据服从特定的分布（通常是正态分布）：

```
t 检验：        假设数据服从正态分布（或大 n 下由 CLT 保证）
方差分析（ANOVA）： 假设正态性和方差齐性
皮尔逊 r：      假设双变量正态性
```

**非参数检验**不依赖于分布假设：

```
Mann-Whitney U：     比较两组（替代独立样本 t 检验）
Wilcoxon 符号秩：    比较配对数据（替代配对 t 检验）
斯皮尔曼 rho：       基于秩的相关性（替代皮尔逊）
Kruskal-Wallis：     比较多组（替代方差分析）
```

**何时使用非参数检验：**

```
- 小样本量（n < 30）且数据明显非正态
- 有序数据（评分、排名）
- 存在无法去除的严重离群值
- 有偏分布
```

**何时使用参数检验：**

```
- 大样本量（CLT 使检验统计量近似正态）
- 数据大致对称且没有极端离群值
- 更高的统计功效（更能检测到真实差异）
```

在机器学习实验中，你通常有较小的 n（例如 5 或 10 个交叉验证折），因此像 Wilcoxon 符号秩这样的非参数检验往往比 t 检验更合适。

### 中心极限定理：实际意义

中心极限定理指出，随着样本量 n 的增长，样本均值的分布趋近于正态分布，无论总体的分布是什么。

```
如果 X_1, X_2, ..., X_n 是独立同分布的，均值为 mu，方差为 sigma^2：

    X_bar ~ 正态(mu, sigma^2 / n)   当 n -> 无穷

在大多数情况下，n >= 30 时成立。
对于高度偏斜的分布，可能需要 n >= 100。
```

**为什么这对机器学习很重要：**

```
1. 为聚合指标上的置信区间和 t 检验提供了理论依据
2. 解释了为什么即使在单个折上差异很大时，对交叉验证折取平均也能得到稳定的估计
3. 小批量梯度下降之所以有效，是因为一个批次上梯度的平均值近似于真实梯度（CLT 在起作用）
4. 集成方法：对许多模型的预测取平均，比任何单个模型都能产生更稳定的输出
```

**CLT 不能做什么：**

```
- 不会使你的数据变成正态分布。它使样本的**均值**变成正态分布。
- 不适用于方差不存在的重尾分布（柯西分布）。
- 不适用于相关数据（未经校正的时间序列）。
```

### 机器学习论文中常见的统计错误

1. **在训练集上测试。** 保证过拟合。始终留出模型在训练期间从未见过的数据。

2. **没有置信区间。** 只报告一个单一的准确率数字而不带不确定性，使得结果不可复现、无法验证。

3. **忽略多重比较。** 测试 50 种配置并报告最好的一个，而不进行校正，会抬高假阳性率。

4. **混淆统计显著性与实际显著性。** 在 0.01% 的准确率提升上得到一个 0.001 的 p 值，这是没有意义的。

5. **在不平衡数据上使用准确率。** 在一个 99% 负类的数据集上达到 99% 的准确率，意味着模型什么都没学到。请使用精确率、召回率、F1 或 AUC。

6. **挑选指标。** 只报告你的模型胜出的那个指标。诚实的评估应该报告所有相关指标。

7. **训练/测试划分之间信息泄露。** 在划分之前进行归一化，或者使用未来的数据来预测过去。

8. **小测试集且没有方差估计。** 在 100 个样本上评估后声称 2% 的提升，那是噪声，不是信号。

9. **在数据不独立时假设独立性。** 来自同一患者的医学图像、来自同一文档的多个句子。组内的观测值是相关的。

10. **p 值操纵（P-hacking）。** 不断尝试不同的检验、子集或排除标准，直到得到 p < 0.05。结果是搜索过程的人造产物。

## 关键术语

| 术语 | 定义 |
|------|------|
| 均值 | 总和除以个数。对离群值敏感。 |
| 中位数 | 排序后数据的中间值。对离群值鲁棒。 |
| 标准差 | 方差的平方根。以原始单位衡量离散程度。 |
| 百分位数 | 给定百分比例的数据落在其下的值。 |
| IQR | 四分位距。Q3 减 Q1。中间 50% 数据的散布范围。 |
| 皮尔逊相关系数 | 衡量两个变量之间的线性关联。范围 [-1, 1]。 |
| 斯皮尔曼相关系数 | 使用秩衡量单调关联。 |
| 协方差矩阵 | 所有特征之间成对协方差的矩阵。 |
| 零假设 | 无效果或无差异的默认假设。 |
| p 值 | 在零假设为真的前提下，观察到如此极端数据的概率。 |
| 置信区间 | 在给定置信水平下，参数可能取值的范围。 |
| t 检验 | 检验均值是否有显著差异。使用 t 分布。 |
| 卡方检验 | 检验观察频数与期望频数是否有显著差异。 |
| 效应量 | 差异的大小，与样本量无关。常用的有 Cohen's d。 |
| Bonferroni 校正 | 将显著性阈值除以检验次数，以控制假阳性。 |
| 自助法 | 有放回重采样，用于估计抽样分布。 |
| 第一类错误 | 假阳性。当 H0 为真时错误地拒绝了它。 |
| 第二类错误 | 假阴性。未能拒绝一个错误的 H0。 |
| 统计功效 | 正确拒绝一个错误 H0 的概率。功效 = 1 减去第二类错误率。 |
| 中心极限定理 | 随着样本量增大，样本均值的分布趋近于正态分布。 |
| 参数检验 | 假设数据服从特定分布（通常是正态分布）。 |
| 非参数检验 | 不依赖于分布假设。基于秩或符号。 |
